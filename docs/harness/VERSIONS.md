# Version stamps

Generated by `python3 eval/versions.py --write` from the source; `eval/test_versions.py` fails when this page no longer matches the code. Bump a stamp in the same change that alters what it covers (`docs/STANDARDS.md` section 4), and record why in that constant's comment.

Versions are not in the model's prompt: the model gains nothing from them, and a changing prefix would break the prompt cache. Every game line records them, so a result names the interface it was measured on.

| stamp | value | game line | a change means |
|---|---|---|---|
| `LlmSpikeGui.HARNESS_EPOCH` | `harness-epoch-53` | `harness_epoch` | the interface the model plays through, as one number: any change to what the seat is asked or shown, or to how its answer is carried out. Results pool only within one epoch. |
| `SeatObservation.VERSION` | `observation-faithful-v41` | `observation_version` | the faithful state the seat reads: the blocks, their labels and their order. |
| `AnswerTool.VERSION` | `answer-tool-v11` | `answer_tool_version` | the `answer` and `set_plan` functions and their validation. |
| `NativeTools.VERSION` | `seat-tools-v11` | `native_tools_version` | the lookup tools' definitions (inspect, search, read, simulate). |
| `ContextMemory.VERSION` | `evidence-tools-v4` | `memory_tools_version` | what the evidence lookups return. |
| `PlayerLookahead.VERSION` | `lookahead-preview-v12` | `lookahead_version` | the `simulate` preview and the attack outlook. |
| `RulesTool.VERSION` | `rules-tool-v1` | `rules_tool_version` | the comprehensive-rules lookup. |
| `ChatSessionBridge.VERSION` | `one-chat-v3` | `one_chat_version` | the one-conversation-per-seat arm (ONE_CHAT). |
| `ChatSessionBridge.TURN_VERSION` | `turn-chat-v1` | `turn_chat_version` | the conversation bounded by the turn (TURN_CHAT). |
| `FORGE_COMMIT` | `34a8662b7966` | `engine_sha` | the pinned Forge engine; results compare only within one engine version. |

Also on every game line: `context_profile` and `context_sha` (the observation profile and a hash of its template), `overlay_sha` (every overlay source), `deck_sha`, and, for a panel, the benchmark version (`eval/benchmark_version.py`).
